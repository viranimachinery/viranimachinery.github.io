### 3. File Optimization & Formatting Standards
- **Format:** Modern `.webp` format for all images with fallbacks.
- **Compression:** Lossless/high-quality WebP (~85–90% quality), resulting in lightweight files (30KB to 90KB each).
- **Naming Convention:** Human-readable filenames without random strings (e.g., `CPVC Brass Elbow.webp` instead of `product15.png` or `o_1j224...`). This automatically generates clean titles in the UI viewer.
